# Upload instructions
1. Create public repository `SER-Research` with README off, gitignore none, license none.
2. Extract this ZIP on your computer.
3. In the empty repository choose `uploading an existing file`, or `Add file > Upload files`.
4. Drag the **contents of** `SER-Research_GitHub_Ready` (not the enclosing folder) into GitHub; check paths and commit to `main`.
5. Commit message: `Initial SER-001 preliminary research milestone`.
6. Inspect README, PDF and license links before creating a GitHub Release.
7. Do not upload historical experiment ZIPs until rights/provenance review is complete.
