# SER — State Evolution Research

**Open research program | Preliminary milestone SER-001 | Not peer reviewed**

**Author:** Dastan Arakeev Mederbekovich  
**Affiliation:** Independent Researcher, Kyrgyzstan

SER investigates attribution of computation in physical systems, interface dependence, and resource accounting. This repository records **ongoing preliminary research**. It does not establish a universal invariant or independently validated protocol.
